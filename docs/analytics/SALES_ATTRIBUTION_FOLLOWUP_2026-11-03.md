## Local implementation

Existing experiment launch/read/stop responses add `conversion_comparison`. Existing `causal_uplift` stays null for compatibility and because complete provider measurement is unverified. The comparison uses full-precision distinct converted visitors / assigned visitors, not rounded API rates, order counts, impressions or clicks. Repeated orders cannot raise conversion probability above one. Existing EUR, ingestion, payment, assignment window and consent-revocation filters remain authoritative. Refunds can remove a converting visitor when no qualifying net-paid order remains. All assignments stay in denominators, including expired/revoked assignments; this does not establish equal observation windows.

`absolute_difference` is variant minus control probability; multiply by 100 for percentage points. `relative_change` divides that difference by control probability, and is null at zero control conversions. Missing arms return null estimates. Fewer than ten successes or failures in either arm returns `insufficient_data`, with no interval, p-value, significance or favored arm. Otherwise an unadjusted pooled two-proportion z-test reports two-sided p-value, 95% unpooled Wald difference interval and a statistical favored arm at p < .05. The normal-tail approximation has absolute CDF error below 7.5e-8; values are rounded to eight decimals. This is exploratory, with no sequential/multiple-testing correction, sample-ratio validation, power guarantee, predefined decision rule or causal certification. `winner` is always null; `winner_status` explains the missing provider measurement and analysis plan. Stopping does not unlock a winner: late callbacks, observation maturity and refunds still matter.

Method references: [NIST difference of proportions test](https://www.itl.nist.gov/div898/software/dataplot/refman2/auxillar/diffprop.htm), [NIST difference interval](https://itl.nist.gov/div898/software/dataplot/refman1/auxillar/diffprop.htm). A significant result alone cannot prove complete storefront capture or incremental sales. A release-grade winner requires verified control/variant propagation, comparable completed follow-up, a fixed metric/horizon/sample plan, allocation diagnostics and an explicit multiple-testing policy. There is no new automatic publish or financial action.

The analytics page in the existing working tree already uses shared NL/EN/DE dictionary strings, locale-aware money/count/date formatting and chart labels. This follow-up repairs its browser fixture's missing CSRF cookie after the session bootstrap change. Existing page and translations are preserved.
